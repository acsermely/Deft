# Recipes

Read only the file that matches your question. SKILL.md has the rules; these have the detail.

- `references/recipes/bridge.md`: read when writing `manifest.json` (capability `reason`), calling phone features, migrating `window.deftBridge` (FL200), a wallpaper page or an IME keyboard page.
- `references/recipes/persistence.md`: read when saving data (`store()`, migrating raw `localStorage`, data that only grows), sharing state between modules, or splitting a long `main.js` (FL502).
- `references/recipes/layout.md`: read for a list filled after load, media grid, hero cover, rows holding controls, list choice, single screens, which action is primary, a sheet Back closes, overlays over a canvas, gauges, `<deft-number>`, `[hidden]`, accent in SVG/canvas, destructive buttons.
- `references/recipes/widgets.md`: read when a home widget shows live data (feed, `net.fetch`, cache, sizes, empty, stale and error states, `deft.open` on tap, periodic cost).
- `references/recipes/tools.md`: read when the agent needs a tool app (`tools` in the manifest, isolate or page handler, limits).
